# 威胁模型、权限与部署边界

## 信任与数据流

浏览器问题、标题和操作参数全部不可信。HTTP 只接受固定路由和严格字段；状态目录由启动者指定并经安全检查，任务目录由服务生成 UUID。HTTP 进程管理自己的索引；固定子进程执行既有离线工作流。P1 资料和 P3 返回内容仍按不可信证据处理，不能授权执行、写入或批准。

| 威胁 | 已实现控制 | 验证与剩余边界 |
|---|---|---|
| 恶意网页驱动本机接口 | 精确 Host/Origin、跨站拒绝、每实例 CSRF、JSON | HTTP 行为测试；同 OS 账户可读取本机服务，不是多用户认证 |
| 标题/证据 XSS | HTML 转义、纯文本、无外部脚本、CSP | 浏览器恶意标题测试；不渲染原始 Markdown HTML |
| 路径穿越与秘密读取 | 客户端仅任务 ID，静态路由白名单、拒绝符号链接/reparse 状态根 | 测试任意路径与状态目录；恶意管理员竞态替换不在本版防护范围 |
| 模型输出越权 | 固定脚本、严格原合同、工具 allowlist、双审批 | 真实 P3 MCP E2E；不启用任意工具或真实模型 |
| 重复决定/过期审批 | request_id 唯一预留、payload hash、审批 hash、busy | 幂等、冲突、过期、队列测试 |
| 崩溃遗漏操作 | SQLite 原子预留、启动标记 interrupted、显式 recover | 应用中断模拟与已完成真实工作流重启恢复；非任意进程时刻故障全覆盖 |
| 资源耗尽 | 8192 字节正文、8 个待执行 job、200 任务、1000 job、120 秒 worker | 超大输入/队列/超时验证；下载和 HTTP 并发尚无生产级限流 |
| 审计泄密 | 固定错误消息、关闭请求日志、子进程 stderr 不回显 | 本地代码和错误响应检查；不记录 Key，不读 .env |

只读默认适用于 P3 工具。用户创建任务、审批与交付会写入**本应用独立状态目录**；权限来自本机用户操作，不是模型指令。归档可逆，不提供删除接口。

## 部署视图

一台 Windows 主机：浏览器 + 标准库 HTTP + 单工作队列 + 三个已有 Python 环境。监听地址硬编码 `127.0.0.1`，只允许调整端口，不提供 `0.0.0.0` 开关。没有 Docker、云资源、反向代理、外部数据库、API Key 或外部依赖下载动作。

默认 `.runtime/` 被 Git 忽略。备份时先正常停止本应用，再由用户备份整个独立目录；不在线复制部分 checkpoint，不将运行数据发布到仓库。应用关闭会等待自己队列当前任务结束（每 worker 最多 120 秒），不停止其他项目服务。

若学校明确要求远程多用户，需先设计认证、RBAC、用户/项目隔离、TLS、CSRF 生命周期、服务进程与操作审计身份，再选正式 Web 服务栈。不得将当前 localhost 版本直接转发公网。费用、安装和发布另行集中授权。

## G2-B补充边界

动态任务最多4个候选/64段/96KiB所选版本正文与分段正文；客户端只提交冻结版本ID，不能传执行路径、MCP工具名或模型配置。服务端保存全文快照与hash，P2子进程检查原文/分段一致性，P1子进程分词，P3只读MCP产双回执。修订限制字段且清除旧批准，下载独立CLI拒绝损坏包和多余成员。旧固定worker仍最长120秒，新冻结worker最长240秒；服务单队列，非生产吞吐保证。恶意同机OS账户替换运行文件、无签名审计身份、真实资料中的社会工程文字和语义误导仍属未解决风险。G3应加认证/权限，G4应做真实语料内容验证。
