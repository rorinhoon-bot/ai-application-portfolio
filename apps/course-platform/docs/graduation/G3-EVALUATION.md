# G3 离线验收方案

在临时目录用三名合成账户和两个研究项目运行 HTTP 行为测试：无会话、错误凭证/锁定、过期/撤销会话、CSRF、重复 Cookie、研究者自批、审核者改资料、跨项目读/搜索/下载、未授权请求无后台副作用、项目审核者不可重派。用合法研究者与审核者完成至少一个真实 P1/P2/P3 离线任务，检查审批事件与 P2 请求/报告指纹关联。检查旧 v1 模式回归仍通过，并用独立 v2 预览浏览器复核登录、角色视图、登出及窄屏。测试不能连接外网、收费模型或原 P1/P2/P3 数据目录。

失败和限制都写结果；通过权限测试不等于公网安全审计或报告内容正确。命令沿用项目已有 P2 `.venv`，不安装依赖。

实际结果、命令及未验证项记录在 `G3-ACCEPTANCE.md` 和 `../results/graduation-g3-tests.json`。测试中五个随机密码仅存在临时进程内存；浏览器演示仅使用新建的合成账户与原创资料。
