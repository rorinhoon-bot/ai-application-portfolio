## 交付与边界

在全新 `course-platform-state-v2-auth` 状态目录，交互式 CLI 建立管理员、研究者、审核者账户。服务使用 scrypt 密码摘要、随机 Cookie 会话、闲置/绝对过期、登出撤销、每会话 CSRF、登录失败锁定。研究项目冻结资料版本并指定另一名审核者；所有资料、项目、任务、搜索、下载和审批 HTTP 路径按服务端身份及归属授权。研究者不能自批，审核者不能编辑资料或报告；管理员可查看最近 200 条允许/拒绝审计。无身份的旧固定任务创建在本模式禁用；v1/v2 状态标记互斥。

P1/P2/P3 离线执行仍由 G2-B 适配器完成。P2 checkpoint 内部审批者仍写 `operator-cli`；应用审计独立关联本机用户、任务与请求。ZIP 不含可独立验证的用户签名。原 P1/P2/P3 代码、数据库、容器、服务和 P2 真实账本未改动。

## 不可宣称与后续
