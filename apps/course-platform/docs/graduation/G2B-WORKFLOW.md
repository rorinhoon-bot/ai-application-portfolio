# G2-B 冻结项目执行、修订与交付设计

2026-09-21。保持旧固定演示运行器和P1/P2/P3源代码不变，新增应用内适配器调用真实P2 build_v2_graph、SqliteSaver、OperationLedger、V2Exporter及P3 stdio只读工具。P1仅复用离线分词组件，不访问向量库或服务；动态资料来源是应用Library不可变版本。

## 产品合同

项目内创建执行任务时，明确选2—4个候选，每个候选绑定一份冻结资料版本和名称；目前每份资料仅属于一个候选。比较维度固定为工具调用、人工审批、恢复，不能把任意领域的资料视为已经适配。最多64段、正文总计96KiB，超出必须明确拒绝，不能悄悄截断。创建动作只生成独立任务，仍需原P2范围审批。

task_id关联project_id、contract_hash与execution_hash；后者绑定候选映射、维度和冻结段落。服务端验证客户端expected_contract_hash。执行参数在任务索引的单独绑定表持久化，工作进程只接收服务端构造的快照，路径不来自用户。创建/恢复均验证快照hash。重复请求复用原任务，既有任务不被覆写。

范围批准后，P1 tokenize_sparse在P1解释器生成词元，应用确定性排序只查候选绑定资料；P3 read_note读取命中段落，核对正文/hash、工具权限、snapshot、begin/end审计。P2脚本模型生成有限报告，未知保持未知，不作模型内容质量承诺。不加载真实模型工厂，费用与真实调用均0。

报告阶段允许修改摘要与明确限制，不能任意修改引文或候选关联。修订保存旧报告、修订请求和新hash，将批准hash/revision清空，继续停在原report-gate；仅当前hash可批准。P2原合同最高报告版本为3，因此最多2次人工修订。已完成报告不原地编辑。重试通过请求ID和修订事件匹配，避免重复升版本。

交付下载包含当前报告、冻结范围/执行合同、原始段落、P2报告合同、批准/修订记录与P3回执。下载先独立复核摘要、来源归属、报告hash、两门审批和MCP对应关系；确定性ZIP，重复下载不重做工具调用。新包有单独schema和验证器，不伪装原graduation-delivery-v1。

## 状态、失败与边界

复用现有异步队列/busy/超时和重启中断标记；失败只显式恢复，不自动批准。P2真实预算不变，独立本地ledger仅用于scripted-offline操作幂等。无网络、安装、云服务或原数据库操作。资料更新不改变执行快照。文档内容、候选名、摘要按不可信数据处理，页面转义；报告Markdown中的原文也不是指令。

测试覆盖新合同范围、候选越界/重复/容量、同请求重试与冲突、真实P2图两门审批/P3回执、修订旧hash拒绝、重启恢复、确定性下载、损坏包拒绝、无证据及拒绝路径，并保留旧49项。人工修订和操作者批准不等于独立质量评分。后续仍需多用户身份、真实语料实验、学校要求对齐及新环境复现。
