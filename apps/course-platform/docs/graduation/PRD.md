# 技术选型研究与审批系统：毕业设计需求 v2

2026-09-19。用户已接受保留P1/P2/P3、面向软件项目技术选型的方向；学校选题审批尚未完成。本文是拟实施的产品需求，不冒充用户访谈或学校评分表。

## 用户与价值

研究者整理候选技术的授权资料，提出约束，检索并整理可追溯依据；审核者检查证据与结论，批准特定版本后交付。目标是减少来源遗漏、过期证据、未审批交付和失败后重复执行。真实需求访谈、时间节约幅度和用户满意度尚未测量。

## 分阶段验收

| 阶段 | 功能与完成条件 | 当前执行边界 |
|---|---|---|
| G1 资料基础 | UTF-8 TXT/Markdown导入、授权说明、来源标签、不可变版本、段落/行号/hash、跨资料查询、稳定空结果、容量控制、操作审计 | 本轮实施；本机单用户，不读用户未选择的文件 |
| G2 研究工作流 | 项目约束、动态候选、冻结资料版本的研究任务、证据摘录与人工修订、审批/导出 | 后续阶段；先写合同，不修改P2既有夹具或历史结果 |
| G3 协作权限 | 研究者/审核者账号、服务端归属和审批授权 | 后续；当前本机信任边界不能宣称已有身份隔离 |
| G4 评估与复现 | 真实授权资料评估集、检索对比、内容人工评审、新环境启动、论文材料 | 后续；学校要求、数据及外部资源确认后执行 |

G1验收：用户显式选择或粘贴文本并确认拥有使用授权；无需网络和模型。文件名只是标签，不作为路径；网页只显示转义文本。修改资料生成新版本，旧版本和定位可查；并发更新必须匹配最新版本，重复请求不重复创建。查询返回相关段落及版本，未匹配不编造答案。保存成功后刷新和重启仍能读取。

## 范围与限制

资料库与原“离线示例”入口分别标注。新资料暂不参与固定graph-plan/chain-plan报告；创建资料不触发P2、MCP、模型或远程抓取。G1检索为确定性词法排序，不称语义检索、P1向量服务或内容质量验收。原始文本可能包含恶意指令，作为普通数据保存/搜索，不执行HTML、命令或工具。

本版不读取.env/密钥，不自动下载正式资料，不安装依赖，不访问原数据库/容器/服务。P2的¥5永久上限、417/500分占用、109/109容量冻结继续生效；不得通过新模式绕过。

学校与个人贡献：用户需与导师确认选题、既有成果复用及AI辅助披露规则。助手实现和测试不得记为学生独立工作。

## 实施状态补充：G2-B（2026-09-22）

上文描述G1拟实施范围，不能用作当前全部能力列表。现已支持2—4候选与冻结资料版本的明确绑定、双审批下的离线P2研究、P3只读MCP查证、最多两次人工摘要/限制修订及独立ZIP校验。验收为：审批前0模型/MCP读取；报告引用仅限冻结段落；旧哈希不可批准修订后报告；损坏包拒绝；离线完整回归通过。固定三维、词元交集排序、脚本模型和本机单用户是明确范围。需求变化或老师要求出现时先做条款差距映射，再设计身份/内容实验，不直接宣称满足学校要求。
