# P3 V2 PRD

2026-09-16，设计先于实现。范围：可信 AI 应用方案研究与交付平台的受控工具服务。助手实现，学习者独立实现/解释尚未验证。

## 用户与流程

本地研究工作流需要读取经批准笔记，并核验正文身份；工具异常必须能区分“没有匹配”与“未能读取”。默认只读 stdio，无任意路径、URL、SQL、命令工具，无真实模型调用。公开V1历史保留，不以历史完成状态替代V2验收。

工具：`search_notes(keyword)` 返回最多5条可追溯摘要；`read_note(note_id)` 只接受登记ID，返回有限原文和SHA-256。`create_task(title, description)` 仅在可信启动配置显式启用时出现；复用V1待确认意图，批准仍在 MCP Tool 外。只读 Resource 描述合同和快照身份。

## 硬验收

1. 实际 MCP `tools/list` 发布严格输入/输出 JSON Schema；未知字段、错误类型、越界长度都失败，`structuredContent` 与兼容文本内容一致。
2. 所有业务失败携带稳定码且 `isError=true`。索引故障不能返回空成功；全文严格UTF-8，实际字节哈希必须匹配登记哈希。
3. 路径完全由安全登记映射。读采用既有Windows句柄安全层；资料冻结在内存，提供快照哈希。上限64条、单条8KiB、合计256KiB；不跟随笔记内指令。
4. 默认无写工具，无任务数据库初始化。可选写意图必须明确启用并提供可信配置；写文件前必须Tool外批准。未知批准结果不自动重试。
5. 每次工具尝试记录服务端调用ID、工具名/安全未知标记、参数哈希、结果哈希、错误码、开始/完成事件。正文和参数原值不入审计；审计不可用时失败关闭。
6. 单次调用超时；只读瞬时故障最多2次尝试；非法输入/越权/快照漂移不重试；只读重放保持数据身份。写意图不自动重发，沿用内容幂等与PUBLISHING恢复。
7. 保留240项旧测试与40例旧评估；新增行为、协议、故障、安全与固定评估。测试仅使用新临时目录，不操作任何既有数据库/服务，不读.env，不访问外网。
8. README、配置示例、演示、失败记录、评估结果、限制、学习文档齐全后才允许阶段C。
