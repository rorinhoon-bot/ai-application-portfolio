## 核心取舍与学习参与

- 先用真实官方资料的固定快照：既能研究真实问题，也能复查同一份证据。代价是必须明确资料日期，不能声称实时。
- 保留单个状态图：P2 已有审批、恢复和导出能力，重写或引入多智能体会增加成本，当前没有收益证据。
- 去掉生产链中的答案白名单：程序能确认引用来自哪份资料，不能靠字符串相等证明模型理解正确。
- checkpoint 记住图走到哪里；调用账本记住钱可能花到哪里。两者需要协调，不能假设恢复就不会重复计费。
- CLI 先实现完整用户流程；本地 UI 作为后续增强，服务化、Docker 和云部署不作为此次 MVP 的前置条件。

本设计由 AI 助手审查与整理；学习者已确认产品方向、资料范围及模型选择，理解检查尚未回答。不得描述成学习者独立设计或实现。

理解检查：

1. 为什么「引用绑定 100%」仍不能说明报告事实正确？
2. 模型超时后不知道供应商是否已计费，恢复时为什么不能直接重试？
3. 报告改了一个字，旧人工批准为什么必须失效？
4. 哪些证据缺口允许出有限简报，哪些必须阻止推荐？
5. 为什么真实文档固定快照比每次联网搜索更适合第一版？它牺牲了什么？
