## 能力等级

统一使用以下等级：

- `0`：尚未学习或缺少任何证据。
- `1`：已学习概念，能在复习后解释基础术语。
- `2`：能在指导下实现，并有可运行代码或实验结果。
- `3`：能独立设计、实现、测试和解释，并有作品证据。

当前交接包中，已覆盖技术统一标记为 `1`。作品集阶段的目标是把关键能力从 `1` 提升到 `2` 或 `3`。

## 推荐教学方式

- 不再重复完整概念课程；在实现到对应步骤时快速复习。
- 每次只引入完成当前功能所需知识。
- 先由学习者写设计或核心代码，再进行审查和纠错。
- 不直接代写整个作品；保留架构选择、实现和调试任务。
- 每个技术点必须产生代码、测试、评估结果或决策记录。
- 发现概念理解与实际操作不一致时，以实际验证结果为准。
