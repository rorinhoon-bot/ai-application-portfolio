# AI 应用开发学习成果交接包

## 用途

本目录把“学习网站各节点学习”项目中的路线图、旧对话和本机环境整理为可迁移资料，供后续“AI 应用开发作品集”项目读取。

目标岗位：AI 应用开发相关求职与实习。

## 能力口径

本交接包采用保守口径：

- 路线图显示 PRE、L1～L5 共 28 个节点已完成。
- 旧对话证明学习者接触并学习了相应概念。
- 当前项目目录没有保存节点练习代码或完整项目。
- 用户确认代码练习很少，因此所有技术能力统一记为“已学习概念，独立实现尚未验证”。
- 对话中的自测回答和纠错只作为理解迹象，不升级为独立开发能力。

## 文件说明

- `00-thread-index.md`：28 条学习对话索引。
- `01-learning-profile.md`：学习背景、能力现状和教学建议。
- `02-roadmap-node-index.md`：28 个路线节点与证据、待验证产出的对应表。
- `03-skill-evidence-matrix.md`：技能、证据、能力等级和作品验证方式。
- `04-tools-and-environment.md`：已检测开发环境及待配置工具。
- `05-gaps-and-preferences.md`：能力缺口、求职目标和已确认偏好。
- `06-portfolio-brief.md`：新作品集项目的交接说明和项目顺序。
- `stages/`：PRE、L1～L5 分阶段总结。

## 新项目使用方法

创建作品集项目前，将整个 `handoff/` 目录复制为：

```text
docs/learning-handoff/
```

新项目中的 `AGENTS.md` 应要求每次规划或开发前先阅读：

1. `01-learning-profile.md`
2. `03-skill-evidence-matrix.md`
3. `05-gaps-and-preferences.md`
4. `06-portfolio-brief.md`
5. 当前作品的 `STATUS.md`

只有交接文件信息不足时，才回查旧对话。

## 证据来源与限制

来源：

- 2026-07-24 至 2026-07-27 的 PRE、L1～L5 学习对话。
- AI 应用开发学习路线站点的 28 节点与 8 个候选项目。
- 当前工作目录的只读文件盘点。
- 当前机器的工具版本检测。
- 用户在 2026-07-27 对实际练习、作品集目标和环境偏好的确认。

限制：

- 对话内容以知识总结、解释和参考答案为主。
- 未发现可验证的 RAG、Agent、微调、MCP 项目源码。
- 未验证 Python、Docker、相关 Python 包和模型 API 的可运行状态。
- 每周投入时间和 API 预算未确定。
