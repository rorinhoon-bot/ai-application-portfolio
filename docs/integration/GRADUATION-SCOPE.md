# 毕业设计范围与论文提纲

建议题目：**可信 AI 应用方案研究与交付平台的设计与实现**。

可展示贡献：跨模块证据合同、MCP工具权限、双审批hash绑定、持久化工作流、有界失败恢复、报告与调用审计关联、分维度离线评估。上述是工程实现贡献，不宣称发明新的大模型算法。

建议章节：

1. 背景与问题：无依据回答、不可追溯工具、隐式副作用与恢复难题。
2. 需求分析：用户、输入输出、批准边界、业务和质量验收。
3. 总体设计：P1/P2/P3分层、数据流、权限与威胁模型、进程与依赖边界。
4. 详细实现：知识解析、MCP严格合同、SourceStore适配、审批/审计、checkpoint与no-replace导出。
5. 实验与评估：分别报告工作流、工具安全、夹具检索、进程故障恢复；保留17/18失败与修正结果，不用真实模型质量作离线假分。
6. 局限与展望：独立内容评分、真实检索整合、数据覆盖、身份、多平台和部署。

当前论文必须披露：P1当前树缺HTTP/容器证据；P2真实模型内容未通过（六题2有限批准/4拒绝，修复后三题2有限批准/1拒绝）；5元和109/109调用永久边界，整合只用0费用脚本模型；P3历史9项专项skip；未验证新机器、云部署、负载及学生独立答辩能力。

演示话术：“离线端到端工程原型完成验证”只能在最终验收通过后使用。不可写“生产可用”“已上线”“内容质量达标”或“整套毕业设计完成”。最终论文、真实业务资料、独立人类评分和学校具体毕业要求仍需后续工作。
