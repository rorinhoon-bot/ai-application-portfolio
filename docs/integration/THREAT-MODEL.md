# 威胁模型

- 攻击面：问题、检索词、HTML/Markdown正文、MCP结果、恢复run_id、审批内容、运行目录。
- 提示注入：所有资料只作为不可信正文；不执行其中命令/URL/路径；模型没有批准工具。
- 路径逃逸：工具仅接ID；CLI只接符合固定格式的run_id；部署路径由代码固定，拒绝symlink/reparse目录与超出根的路径。
- 引用伪造/漂移：P1原资料hash、章节hash、P3原文hash和返回快照hash交叉验证；批准绑定请求/报告hash，过期批准不能用于新内容。
- 外部调用：worker环境allowlist，不传任何模型Key/追踪配置；进程网络阻断，不加载.env。P3 Windows内部事件循环回环允许，不访问既有服务。
- 重放：P2 checkpoint和内容寻址无覆盖导出；重复批准不重启研究；未知结果不重发写；P3只开放读。
- 故障：子进程失败/超时/异常JSON/未知字段/审计缺失时失败关闭，不把空结果替代失败。只读可有限重试；写后未知保留给恢复检查。
- 边界：本机可信OS用户可改任何文件，hash非认证签名；不宣称恶意管理员防护、多租户、网络隔离沙箱或分布式exactly-once。
