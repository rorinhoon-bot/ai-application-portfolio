# 权限与部署边界

本地CLI操作者是可信Host。需求批准和报告批准分两次，真实用户使用明确approve命令；演示/自动测试使用显式标注的scripted approval，不声称真人评过内容。批准范围限当前run/hash，拒绝或取消不导出。

P1仅处理整合自编夹具，原P1数据库/服务/容器只读审查之外不操作。P2仅新建隔离测试checkpoint与0成本脚本账本，原109/109容量和417/500分占用不可变。P3仅整合创建的notes/audit目录，未启用业务写工具或旧任务数据库。各方不继承其他项目授权。

本轮不安装依赖、不下载资料、不建云资源、不发布/push。MVP不启动Web/HTTP/容器服务；CLI与stdio均本地短生命周期。新机器复现需用户按三个项目精确锁文件准备环境，当前未重装验证。P1 HTTP/容器能力在当前树未找到；后续替换适配器前须另做契约兼容验收。

若要真实模型、外部资料或部署，先提供具体包版本/许可、来源清单、预算和最小权限方案；P2既有总额与调用上限不可因整合重置。优先继续离线与独立人类内容评分，无须解锁收费能力。
