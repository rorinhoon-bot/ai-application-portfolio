# 作品集计划

## 目标

面向 AI 应用开发岗位求职与实习。用少量完整项目证明工程能力，不追求项目数量。

## 项目顺序

### P0：结构化内容生成器

性质：工程热身，不必作为最终主作品。

验证：

- Python 环境与项目结构。
- HTTP/API。
- 环境变量。
- JSON Schema。
- 异常处理。
- 自动测试。
- Git 提交习惯。

完成后才能进入 P1。

### P1：带引用的知识库问答

核心展示：

- 文档处理与元数据。
- Embedding 和检索。
- 可核验引用。
- 无依据拒答。
- 固定评估集。
- 基线与优化对比。

目标：形成第一个求职级主作品。

### P2：LangGraph 研究报告工作流

核心展示：

- 显式状态图。
- 检索、写作和审校。
- Tool Calling。
- 重试和失败处理。
- Human-in-the-loop。
- 状态持久化与幂等性。

目标：形成旗舰项目。

### P3：本地 MCP 工具服务

核心展示：

- MCP Server。
- Tool 与 Resource。
- JSON Schema。
- 路径安全。
- 写操作边界。
- 自动测试和客户端演示。

目标：形成协议与系统集成作品。

## 后置技术

首批项目完成后，再根据岗位需求选择：

- LoRA 微调与量化。
- GraphRAG。
- A2A。
- 多模态。
- 多智能体。
